# Das Geheimnis der Mumie
Interaktives Exit-Game für den Geschichtsunterricht (Klasse 6). Optimiert für iPads in Safari.

## Start
Die Schüler öffnen die öffentliche Website: https://droeseschule.github.io/aegypten-exit-game/

## Hinweis zur Videodatei
Zum vollständigen Betrieb muss die Datei **video.mp4** im Stammverzeichnis neben **index.html** liegen. Die HTML-Seite wurde bereits veröffentlicht; die Videodatei muss noch hochgeladen werden. Bis dahin bleibt das Video-Rätsel gesperrt.

## GitHub Pages
Eine Deployment-Workflow-Datei liegt unter `.github/workflows/pages.yml`.
In GitHub unter **Settings → Pages → Build and deployment → Source: GitHub Actions** auswählen. Anschließend den Workflow „Website veröffentlichen“ ausführen oder einen Commit auf main erstellen.
